# SUBSENSE reproducible detector evaluation

Generated with `30` independent test seeds per scenario and noise model. Training seeds are the disjoint range `100000`–`100029`; simulator test seeds are `10000`–`10029` and shifted test seeds `200000`–`200029`. All readings use the backend Kalman filter, rolling buffer, baseline tracker, and FeatureExtractor. Confidence intervals are two-sided 95% Student-t intervals across seeds (bounded metrics are truncated to valid ranges). Detection delay averages detected events only; event recall counts missed events in its denominator. PR-AUC is average precision. An `ANOMALOUS` current-system state counts as an alert; `MICRO_ANOMALY` does not. False alarms are rising edges per summed node-hour on the normal and nuisance controls.

The shift set independently adds ±0.12° tilt noise, ±0.06 m/s² acceleration noise, and 0.8–1.2 s sampling intervals. Severity defaults to 1.0. `sensor_failure` represents a stuck tilt sensor plus zero acceleration; rejected/missing packets cannot be scored as feature vectors by the current backend pipeline. Baseline drift is a nuisance with `is_event=false`.

## Method and threshold protocol

All methods share the same extracted backend feature vectors. The fixed tilt detector alerts at 0.50° baseline deviation. The baseline z-score uses the training partition's mean and standard deviation of `tilt_deviation` and alerts at z ≥ 3.0. EWMA uses α = 0.20 and a 0.30° score threshold. CUSUM uses reference value k = 0.08°/sample and threshold 0.80. Isolation Forest uses 100 trees, contamination 0.05, seed 71. One-Class SVM uses an RBF kernel and ν = 0.05; Local Outlier Factor uses novelty mode, contamination 0.05, and up to 35 neighbors. Both SVM/LOF use a StandardScaler fit on the same normal-only training rows as the Isolation Forest. `current_system` is the unchanged `AIEngineDetector` decision rule with that fitted Isolation Forest; only `ANOMALOUS` counts as an alert, while `MICRO_ANOMALY` does not. `current_system_spatial` is the full evaluation composite: the current-system alert plus either three consecutive node alerts or same-step alerts from at least two of the three Z01 nodes. This persistence/spatial policy is an evaluation wrapper, not a change to the production detector. The feature-group ablation `no_acceleration_features` is expected to be a no-op because the current Isolation Forest feature contract does not include accelerometer-derived columns.

Run with `python -m ai_engine.evaluation.run_all --seeds 30`. Optional labelled hardware CSV input: `--real-csv PATH`.
